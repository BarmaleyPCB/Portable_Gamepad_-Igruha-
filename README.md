# Portable_Gamepad_-Igruha-
Портативная игровая мини-консоль на ATmega328P для обучения программированию. Цифро-Аналоговое устройство имеющие акселерометр, Джойстики-слайдеры и OLED-дисплей
# Игруха (Igruha) — Портативный игровой комплекс

**Игруха** — это учебный игровой контроллер на микроконтроллере ATmega328P, разработанный с нуля. Проект объединяет аналоговую схемотехнику, цифровую обработку сигналов и профессиональную разработку печатных плат.

> **Статус:** Проект завершен. Плата спроектирована, заказана и ожидает сборки.

## 🚀 Ключевые особенности
- **Кастомный дизайн платы** в форме геймпада.
- **Двойное управление:** аналоговый джойстик-слайдер, тактовые кнопки SPKM и сенсорная кнопка TTP223.
- **Умные датчики:** акселерометр ADXL345 (наклон/встряхивание) и аналоговая индикация направлений на LM339.
- **Живой интерфейс:** OLED-дисплей 0.96" с анимациями и звуковое сопровождение.
- **Питание и связь:** USB Type-C (CH340N).
