Алгоритм работы программы соответствует требованиям ГОСТ 19.701-90. Устройство работает в бесконечном цикле, опрашивая датчики и обновляя интерфейс.

## Архитектура прошивки

Прошивка написана на языке **C++** в среде разработки Arduino IDE. Код имеет модульную структуру:

- **Инициализация (`setup`):** Настройка шины I²C (`Wire.setClock(400000L)`), инициализация дисплея, калибровка центрального положения джойстика.
- **Графический интерфейс:** Отрисовка стартовой анимации (спрайт геймпада, полоса загрузки), главного меню с навигацией и анимации звёздного фона.
- **Логика навигации:** Опрос аналоговых значений джойстика и сравнение их с порогами (`JOY_ON`, `JOY_OFF`) для переключения между пунктами меню.
- **Экономия памяти:** Спрайты и текстовые строки хранятся в памяти программ (PROGMEM). Для генерации случайных чисел используется собственный алгоритм (`fastRand`), чтобы не тянуть тяжелую стандартную библиотеку `random()`.

### Логика навигации в меню 
Функция `readJoystick` возвращает код события (влево, вправо, вверх, вниз) только при пересечении порога, защищая от дребезга. В основном цикле `loop` эти события обрабатываются для циклического переключения пунктов меню.

```cpp
// Фрагмент из основного цикла
void loop() {
  // Опрос джойстика (возвращает 1, 2, 3, 4 или 0)
  uint8_t ev = (screen == SCR_SPLASH) ? 0 : readJoystick();

  if (screen == SCR_MENU) {
    // Навигация по меню с циклическим переходом
    if (ev == 1) {                          // Стик влево
      if (selected == 0) selected = 2;      // С последнего на первый
      else selected--;
    }
    else if (ev == 2) {                     // Стик вправо
      if (selected == 2) selected = 0;      // С первого на последний
      else selected++;
    }
    else if (ev == 3) {                     // Стик вверх — выбор
      openMode(selected);                   
    }
    
    // Проверка на бездействие (переход в режим ожидания)
    if (millis() - lastActivity >= IDLE_MS) screen = SCR_STANDBY;
  } 
  
  // Ограничение частоты кадров (~25 FPS)
  if (millis() - lastFrame < FRAME_MS) return;
  lastFrame = millis();

  // Отрисовка текущего экрана
  switch (screen) {
    case SCR_SPLASH:  frameSplash();      break;
    case SCR_MENU:    frameMenu(true);    break;
    case SCR_STANDBY: frameMenu(false);   break;
  }
}
```

## Взаимодействие с аппаратной частью 

Перед написанием полной игры, работа акселерометра ADXL345 проверялась отдельным тестовым скетчем. Он демонстрирует инициализацию датчика по шине I²C и чтение сырых данных с трех осей.

```cpp
void loop() {
    Wire.beginTransmission(ADXL345_ADDR);
    Wire.write(0x32);  // Начинаем чтение с регистра DATAX0
    Wire.endTransmission(false);
    Wire.requestFrom(ADXL345_ADDR, 6);

    if (Wire.available() >= 6) {
        int16_t x = Wire.read() | (Wire.read() << 8);
        int16_t y = Wire.read() | (Wire.read() << 8);
        int16_t z = Wire.read() | (Wire.read() << 8);

        Serial.print("X: "); Serial.print(x);
        Serial.print("  Y: "); Serial.print(y);
        Serial.print("  Z: "); Serial.println(z);
    }
    delay(500);
}
```
